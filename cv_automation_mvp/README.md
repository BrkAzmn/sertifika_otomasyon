# CV Automation MVP Skeleton

This folder contains the initial skeleton for an application that generates
job-specific, ATS-friendly CVs from user profile data and a job post text.

## Architecture

- `backend/`: FastAPI API skeleton
- `frontend/`: Next.js planning notes

## Next implementation steps

1. Job post parser service (keywords, seniority, requirements)
2. Profile-job matching and scoring engine
3. CV composition and ATS optimization
4. PDF renderer and downloadable artifact storage
5. Authentication and user profile persistence
